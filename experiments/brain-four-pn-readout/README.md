# DM1／VA2の4 PN：ON保持・OFF静穏・再ON回復

DM1／VA2に対応する4個の投射ニューロン（PN）について、刺激中・刺激停止後・再刺激時の発火を比較した。既知正符号eLN→PN入力を停止期間だけ遮断した条件では、初回の刺激応答を保ちながら停止後の発火が0となり、再刺激で応答が回復した。4乱数seed×2入力利得の8組すべてで、この時間応答を確認した。

## 観測細胞と入力遮断

- 読むのはDM1_lPN `10176 / 10208`、VA2_adPN `10390 / 10561` の4細胞。
- 止めるのは全686 ALPNへ到来する既知正符号ALLNの11,069辺（ACh 10,944＋octopamine 125）。unclearと負入力は通す。「既知」は模型内のラベル定義。
- 刺激のON／OFFは固定スケジュールで与えた。入力遮断のタイミングもこの時刻表に従う。
- 全686 ALPN平均やVP3集団とは分けて、DM1／VA2の4細胞を集計した。

TRN切断・温度の意味づけ・新たな適応項を足していない。前のOFF20秒集計だけではONピークと再ONを復元できなかったため、個別4 PNの1 ms発火カウンタを追加し、同じ16試行を再実行した。

## 時間窓と判定

| 指標 | 計算窓 |
|---|---|
| 初回・再ONピーク10／50 ms | 各ON内に完全に収まる移動平均の最大。1 msずつ移動 |
| 刺激後半 | 各ONの最後500 ms |
| OFF1秒・再OFF1秒 | OFF後900〜1000 ms |
| OFF20秒 | 初回OFF後19900〜20000 ms |
| 個別細胞の静穏 | 4細胞それぞれの上記OFF指標が0か |
| 静穏継続 | OFF1秒以後〜再ON／記録終了の全発火数 |

ピークは対応する対照の70%以上、後半は30%以上、OFF平均は3 Hz以下を操作的参考値とした。再刺激ピークは同一試行の初回との比も70%以上、再ONの50 msピークがOFF20秒より高いことも判定する。個別0 Hzと参考平均3 Hz以下は別項目。閾値は生理学的な確定値ではない。

| 指標：4 PN平均 | control（8試行） | known_positive（8試行） |
|---|---:|---:|
| 初回ピーク10 ms | 450〜500 Hz | 450〜500 Hz |
| 初回ピーク50 ms | 410〜455 Hz | 410〜455 Hz |
| 初回後半500 ms | 391.5〜429.5 Hz | 391.5〜429.5 Hz |
| OFF1秒 | 330〜350 Hz | 0 Hz |
| OFF20秒 | 335〜352.5 Hz | 0 Hz |
| 再ONピーク10 ms | 425〜500 Hz | 450〜500 Hz |
| 再ONピーク50 ms | 410〜450 Hz | 410〜450 Hz |
| 再ON後半500 ms | 392.5〜432 Hz | 393.5〜432.5 Hz |
| 再OFF1秒 | 332.5〜352.5 Hz | 0 Hz |

対応する対照に対し、初回両ピーク・後半はすべて100%。再ONの50 msピークは98.8〜101.1%。停止条件8/8で、個別4細胞のOFF1秒・20秒・再OFF1秒が厳密に0。OFF1秒以後も次のON／終了まで全細胞無発火だった。

初回・再OFFの計16区間のうち4区間はOFF内発火なし。発火があった区間も最後の1 msビンの上端は最大3 ms。これは記録ビンの上端で、正確な発火時刻ではない。

## 記録追加の同一性

新しいカウンタ追加後も16試行×既存9ファイル＝144ファイルが前の記録とバイト一致した。全PN累積値、集団・ORNカウンタ、入力・到来・境界記録を含む。新しい4 PNカウンタも過去4時点の個別累積値と一致。初回ON終了までの4 PN記録は対照と停止条件で完全一致。ピークを累積和と独立なNumPy畳み込みで照合した。

[個別4細胞CSV](results/cells.csv)、[記録追加の検証](results/final-verification.json)と各試行の検証JSONを保存。1 msの全記録は参照ハッシュのみ配布し、再実行で復元する。

## 結果の適用範囲

観測対象は4 PN、入力遮断先は全686 ALPNである。遮断のタイミングは固定した刺激スケジュールから与えた。この結果が示すのは指定した4細胞の時間応答であり、全PNの沈黙、神経活動からの自律的な刺激停止検出、別の刺激条件での応答は検証していない。

## 条件とデータ

実験条件は [protocol.json](protocol.json)、対象集団は [cohorts.json](cohorts.json)、判定表は [decision-table.csv](decision-table.csv)。各停止条件は元回路から開始する。

4seed `2026091701, 2026091711, 2026091721, 2026091731` ×入力利得1.0／0.5。DM1／VA2 ORN 157細胞へ60 Hz×利得。無入力0.5秒→ON1秒→OFF20秒→再ON1秒→再OFF2秒。dt=0.5 ms、遅延2 ms、回路gain=0.65、KC gain=0.25、単一worker、50 ms endTick。その他は固定上流LifConfig。

OFFの積分直前に、その到来時刻で停止対象だけを除いた入力へ差し替える。元のfloat加算順を保ち、遅延バッファの非零件数を整合させる。ON末尾発信→OFF到来は止め、OFF末尾発信→再ON到来は通す。膜電位・到来済みシナプス状態のリセットは行わない。

[結果CSV](results/summary.csv)・[指標JSON](results/report.json)は元の測定から保存した値。[コピー同一性](byte-copy-manifest.json)、[省略した生記録の参照ハッシュ](reference-hashes.json)、各試行の検証JSONを併記する。生の全ステップは配布せず、再実行で生成してSHA256を照合する。記録ハッシュ自体は生理的妥当性の証明ではない。

## 再実行

```sh
.venv/bin/python experiment.py --seed 2026091701 --gain 1 --gate known_positive \
  --jdk /path/to/jdk-25/bin --out runs/four-pn-seed1
```

`known_positive` では対応する `control` も新しく回し、指標と対照比を計算する。4seed×2利得で繰り返せば元の16試行になる。`control` 単独指定も可能。返る指標JSONは保存済みreportとも照合する。
